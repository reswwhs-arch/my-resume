# Портфолио навыков — Сыймык Шарабидинов

Статический сайт-портфолио на React + Vite, опубликованный на Cloudflare Pages.

## 🚀 Как запустить локально

```bash
npm install
npm run dev
```

Сайт откроется по адресу http://localhost:5173

## 📦 Сборка для продакшена

```bash
npm run build
```

Результат сборки будет в папке `dist/`.

Для предпросмотра сборки:
```bash
npm run preview
```

## 🔄 Как обновить сайт

1. Внеси изменения в код
2. Протестируй локально: `npm run dev`
3. Собери проект: `npm run build`
4. Запуш изменения в GitHub:
   ```bash
   git add .
   git commit -m "Описание изменений"
   git push
   ```
5. Cloudflare Pages автоматически соберёт и опубликует новую версию (обычно занимает 1-2 минуты)

## 📁 Структура проекта

- `src/App.jsx` — основной компонент с логикой сайта
- `src/data/skillsData.js` — данные о навыках
- `src/AIChat.jsx` — компонент AI-чата
- `public/` — статические ресурсы (изображения, favicon)
- `vite.config.js` — конфигурация Vite

## 🔧 Технологии

- React 19
- Vite 8
- Lucide React (иконки)
- TailwindCSS (стили)

## 💾 Что сохранить для переноса на другой хостинг

- Весь код проекта (Git репозиторий)
- Папку `public/` со статическими ресурсами
- `package.json` с зависимостями
- `vite.config.js` с настройками сборки
